# Архив разговоров Битрикс24

Веб-инструмент для выгрузки звонков с готовыми расшифровками в CSV UTF-8 BOM.

Откройте https://koptelev.github.io/bot_bit/, вставьте входящий вебхук в поле страницы, выберите даты, ФИО менеджера, длительность, телефон или ID CRM-дела. Нажмите «Сформировать CSV».

Вебхук вводится для каждой выгрузки и не сохраняется в репозитории, URL или хранилище браузера. Запросы идут прямо в указанный портал. CSV формируется в памяти браузера. Новое распознавание не запускается: выгружаются только звонки с готовым текстом.

Нужны права вебхука на CRM, телефонию и пользователей, а также доступ владельца вебхука к звонкам. Наличие текста не сообщает, кто и каким способом запустил расшифровку.

Если портал запрещает прямые запросы браузера (CORS), скачайте архив `bot_bit_github.zip`, распакуйте его и запустите `start_web.cmd`. Локальная страница откроется автоматически; вебхук и фильтры также вводятся в браузере. Требуется Python 3.10+.

GitHub Pages настроен на ветку main, папку / (root). Файлы `index.html` и `browser_export.js` должны находиться рядом. В архиве — исходники локального режима, тесты и подробная инструкция.

Реальный портал без вебхука не проверен. Большие выгрузки делите по периодам; вкладку держите открытой до завершения. Не загружайте вебхук, CSV или журнал в публичный репозиторий.
